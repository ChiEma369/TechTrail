# TechTrail - Backend (BE)

Thư mục backend của TechTrail được chia thành hai phần chính:

1. **`supabase/`**: Chứa toàn bộ cấu hình, schema SQL, migrations, seed data và Edge Functions cho Supabase.
2. **`api/`**: Khung dành cho Custom API Server (Node.js / Express / Fastify / Python FastAPI,...) khi cần xử lý logic riêng biệt ngoài Supabase.
